# Projeto 1 — Landing Page Fitness App

Landing page responsiva criada com HTML e CSS para apresentar um aplicativo de acompanhamento fitness.

## 🌐 Acesse o projeto

- **Site publicado:** https://eriktauil.github.io/dev-fullstack-ia/
- **Código-fonte:** [Projeto1](Projeto1)

## ✨ Funcionalidades

- Apresentação do aplicativo fitness
- Destaque para saúde, exercícios e amigos
- Contagem de calorias
- Treinos específicos
- Compartilhamento de conquistas
- Layout responsivo para computadores e dispositivos móveis
- Chamada para download

## 🛠️ Tecnologias

- HTML5
- CSS3
- Google Fonts — Roboto

## ▶️ Executando localmente

Abra o arquivo [Projeto1/index.html](Projeto1/index.html) diretamente no navegador ou execute um servidor local na raiz do projeto:

```powershell
python -m http.server 8000
```

Depois acesse `http://localhost:8000/Projeto1/`.

## 🚀 Publicação

O projeto é publicado automaticamente pelo GitHub Pages por meio do workflow [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml). Cada atualização enviada para a branch `main` atualiza o site publicado.
